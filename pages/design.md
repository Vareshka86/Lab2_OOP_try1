## Этап №1. Сущность «Книга из библиотеки»

**Что представляет собой объект?** Один экземпляр книги в фонде библиотеки: конкретная книга,
которая стоит на полке, выдаётся читателям и со временем может быть списана.

**Какие данные характеризуют объект?** Название, автор, год издания; положение книги — на полке,
у читателя (и у какого) или списана; сколько раз книгу выдавали.

**Какие действия можно выполнять с объектом?** Выдать читателю, принять обратно, списать;
узнать сведения о книге и вывести её карточку.

**Какие состояния объекта являются недопустимыми?**
- книга без названия;
- год издания раньше появления книгопечатания (около 1450 года), в будущем или не позже года
  рождения автора;
- книга выдана, но неизвестно кому, — или стоит на полке, но записана на читателя;
- выдана списанная книга;
- отрицательное число выдач.

## Этап №2. Таблица проектирования

| Элемент | Описание |
|---------|----------|
| Имя класса | `Book` — книга из библиотеки; вспомогательный класс `Author` — автор книги |
| Поля | `title_` (std::string) — название; `author_` (Author) — автор; `year_` (int) — год издания; `isIssued_` (bool) — выдана ли; `readerName_` (std::string) — у кого книга; `issueCount_` (int) — число выдач; `isWrittenOff_` (bool) — списана ли; `count_` (static int) — число существующих книг |
| Конструкторы | `Book()` — по умолчанию; `Book(title, author, year)` — параметризованный; `Book(const Book&)` — копирования; деструктор `~Book()`; оператор присваивания `operator=` (стандартный, `= default`) |
| Методы чтения | `getTitle()`, `getAuthor()`, `getYear()`, `isIssued()`, `getReaderName()`, `getIssueCount()`, `isWrittenOff()`, `print()`, статический `getCount()` |
| Методы изменения | `issueTo(reader)` — выдать читателю; `returnBook()` — принять обратно; `writeOff()` — списать |
| Инварианты | 1) название не пустое; 2) 1450 ≤ год издания ≤ текущий год и год издания позже года рождения автора; 3) книга выдана тогда и только тогда, когда записано имя читателя; 4) списанная книга не выдана; 5) число выдач не меньше 0 |

Сеттеров вида `setTitle()` или `setIssued()` нет: состояние книги меняют только действия
предметной области — выдача, возврат и списание.

## Сверка с обязательными требованиями

| Требование | Как выполнено |
|------------|---------------|
| Не менее 4 полей различных типов, одно — пользовательский класс | 7 полей; `author_` — объект класса Author |
| Не менее трёх различных типов данных | `std::string`, `int`, `bool`, `Author` |
| Все поля в секции private | Да, доступ — только через публичные методы |
| Конструктор без аргументов с корректным состоянием | `Book()`: «Без названия», автор не указан, текущий год |
| Минимум один параметризованный конструктор | `Book(title, author, year)` |
| Не менее трёх способов создания объекта | По умолчанию, параметризованный, копирования |
| Минимум один конструктор со списком инициализации | Списки инициализации у всех трёх конструкторов Book и обоих конструкторов Author |
| Методы получения значений, константные методы | Все методы чтения и `print()` объявлены `const` |
| Не менее трёх методов изменения, без бессмысленных setter-методов | `issueTo`, `returnBook`, `writeOff` — версия v0.2 |
| Класс обеспечивает корректность состояния, не менее трёх условий | Пять инвариантов, их проверяют конструкторы (v0.1) и методы изменения (v0.2) |
| Метод вывода информации | `print()` |
| Явный деструктор | Версия v0.2 |
| Статический счётчик существующих объектов | Версия v0.2 |
| Файлы `ClassName.h`, `ClassName.cpp`, `main.cpp` | `Book.h`, `Book.cpp`, `Author.h`, `Author.cpp`, `main.cpp`; каждому классу — своя пара файлов |

## Конструкторы и список инициализации

Все конструкторы заполняют поля в **списке инициализации** — после двоеточия, до тела
конструктора:

```cpp
Book::Book(const std::string& title, const Author& author, int year)
    : title_(title), author_(author), year_(year),
      isIssued_(false), readerName_(), issueCount_(0), isWrittenOff_(false)
{
    if (title_.empty()) { throw std::invalid_argument("название книги не может быть пустым"); }
    ...
}
```

Список инициализации создаёт поля сразу с нужными значениями. Без него поля сначала создались бы
со значениями по умолчанию, а потом получили бы новые присваиванием в теле. Для поля `author_`
это важно: объект Author создаётся один раз — копированием переданного автора.

Конструктор не может вернуть «ошибку» как обычная функция. Поэтому при неверных данных он
**бросает исключение** `std::invalid_argument`: создание прерывается, и некорректный объект не
появляется. Вызывающий код перехватывает исключение блоком `try`/`catch`.

`Book()` создаёт корректную «пустую карточку», а `Author()` — автора «Автор не указан» с
неизвестным годом рождения. Конструктор `Author(name, birthYear)` объявлен `explicit`: строка не
превратится в автора незаметно для программиста.

## Методы чтения и const

Методы чтения объявлены с `const` после списка параметров:

```cpp
int getYear() const;
const std::string& getTitle() const;
```

`const` обещает, что метод не меняет объект: компилятор не даст изменить поле внутри такого
метода. Такие методы можно вызывать и у константного объекта. Строки и автор возвращаются по
**константной ссылке**: копия не создаётся, а изменить поле через ссылку нельзя.

## Пример работы программы (v0.1)

```
=== Три способа создать книгу ===

1) Book first;   // конструктор по умолчанию
Книга «Без названия»
  Автор:        Автор не указан
  Год издания:  2026
  Положение:    на полке
  Число выдач:  0

2) Book second("Война и мир", Author("Лев Толстой", 1828), 1869);   // параметризованный конструктор
Книга «Война и мир»
  Автор:        Лев Толстой (род. 1828)
  Год издания:  1869
  Положение:    на полке
  Число выдач:  0

3) Book third(second);   // конструктор копирования
Книга «Война и мир»
  ...

=== Конструктор не создаёт некорректную книгу ===

Book wrong("Мастер и Маргарита", Author("Михаил Булгаков", 1891), 1850);
Книга не создана: год издания 1850 не позже года рождения автора 1891
```

**Проверка.** Отдельная тестовая программа проверила конструкторы и инварианты обоих классов —
23 проверки из 23: пустые имя и название, годы на границах (1449 и 1450, текущий и следующий год,
год рождения автора и следующий за ним), значения по умолчанию, копирование.
