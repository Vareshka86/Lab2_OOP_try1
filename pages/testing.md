# Часть 3. Тестирование класса (этап №3) {#testing}

[TOC]

Версия v1.0. Функция `main()` — тест класса Book, как требует этап №3 лабораторной работы.

## Что требуется

Недостаточно продемонстрировать только правильные действия: нужно проверить реакцию класса на
некорректные операции. Функция `main()` должна содержать минимум следующие этапы:

1. создание объектов;
2. вывод начального состояния;
3. выполнение корректных операций;
4. выполнение некорректных операций;
5. повторный вывод состояния — объект сохранил корректное состояние;
6. проверка независимости объектов — изменить один объект и показать, что остальные не изменились.

Кроме того, в `main()` создаётся минимум три объекта разными конструкторами.

## Как устроен тест

`main()` вызывает функцию `runTests()`, в которой выполняются все шесть этапов. Книги — локальные
объекты `runTests()`: при выходе из неё они уничтожаются, сообщения деструкторов видны до паузы в
конце программы, а `main()` затем проверяет, что счётчик книг равен нулю.

Тест **самопроверяющийся**: после каждой операции он сравнивает ожидаемый результат с полученным и
печатает `[OK]` или `[ОШИБКА]`, а в конце — сколько проверок пройдено. Если есть хоть одна ошибка,
программа завершается с кодом 1.

| Функция | Что делает |
|---------|------------|
| `report(description, passed)` | засчитывает проверку и печатает `[OK]` или `[ОШИБКА]` |
| `expectResult(expected, actual)` | сравнивает результат метода изменения с ожидаемым |
| `expectBookRejected(...)`, `expectAuthorRejected(...)` | пытаются создать объект с неверными данными; проверка пройдена, если конструктор бросил исключение и счётчик книг не изменился |
| `expectInvariants(name, book)` | проверяет все пять инвариантов книги через её публичные методы |
| `stateOf(book)` | снимок всех полей книги одной строкой — чтобы сравнить «до» и «после» |
| `show(name, book)` | выводит имя переменной и карточку книги |

## Этапы теста

| Этап | Что выполняется | Что проверяется |
|------|-----------------|-----------------|
| 1. Создание | `empty` — конструктор по умолчанию; `war` и `master` — параметризованный; `warCopy` — копирования | создано 4 книги, `Book::getCount() == 4` |
| 2. Начальное состояние | вывод всех четырёх карточек | копия совпадает с оригиналом |
| 3. Корректные операции | `war`: выдать, вернуть, выдать снова; `empty`: списать | каждая операция выполнена; у `war` 2 выдачи; `empty` списана |
| 4. Некорректные операции | 7 запрещённых вызовов методов изменения; 4 попытки создать неверную книгу и 2 — неверного автора | каждая операция отклонена; каждый конструктор бросил исключение, счётчик не изменился |
| 5. Повторный вывод | вывод карточек | книги совпадают со снимками до этапа 4; у всех четырёх книг соблюдены пять инвариантов |
| 6. Независимость | меняется только `war` (вернуть и списать), затем только `warCopy` (выдать) | остальные книги, в том числе копия `warCopy`, не изменились |

Особенно показательна пара `war` и `warCopy`: копия создана из оригинала, но это отдельный объект
со своими полями. Списание оригинала не трогает копию, а выдача копии — оригинал.

## Некорректные операции

| Вызов | Почему недопустим |
|-------|-------------------|
| `war.issueTo("Сидоров С. С.")` | книга уже у читателя (инвариант 3) |
| `war.writeOff()` | нельзя списать книгу, которая у читателя (инвариант 4) |
| `empty.issueTo("Иванов И. И.")` | списанную книгу не выдают (инвариант 4) |
| `empty.writeOff()` | книга уже списана |
| `empty.returnBook()`, `master.returnBook()` | книга не выдана |
| `master.issueTo("")` | имя читателя пустое (инвариант 3) |
| `Book("", ...)` | пустое название (инвариант 1) |
| `Book(..., 1400)`, `Book(..., 3000)` | год издания вне диапазона 1450 — текущий год (инвариант 2) |
| `Book(..., Author("Михаил Булгаков", 1891), 1850)` | год издания не позже года рождения автора (инвариант 2) |
| `Author("", 1900)`, `Author("Автор", -5)` | пустое имя, недопустимый год рождения |
