# Лабораторная работа №2 по ООП

[![Release](https://img.shields.io/github/v/release/Vareshka86/Lab2_OOP_try1)](https://github.com/Vareshka86/Lab2_OOP_try1/releases)

Класс Book (книга из библиотеки) на C++14 — консольная программа по лабораторной работе №2.

Программа выполняет [лабораторную работу №2](https://aleksandr-003.github.io/labs/OOP_z/Labs1_2.html) курса «Объектно-ориентированное программирование и проектирование» (А. Д. Смородинов), вариант 5 — «Книга (из библиотеки) — Book». Работа сдаётся по частям: каждая часть выходит отдельной версией. Сейчас выполнены части 1 и 2 из 3: класс спроектирован, реализованы конструкторы, методы чтения и изменения, деструктор и счётчик объектов.

```console
$ .\build\lab2.exe
...
war.issueTo("Петров П. П.")   // книга уже выдана
  Отказ: книга «Война и мир» уже у читателя (Иванов И. И.).
  -> отклонено
...
Book::getCount() = 2
{   // начало блока
  [+] Создана книга «Мастер и Маргарита» (конструктор копирования). Книг сейчас: 3
  [+] Создана книга «Без названия» (конструктор по умолчанию). Книг сейчас: 4
    Внутри блока Book::getCount() = 4
}   // конец блока: объекты copy и empty уничтожаются
  [-] Уничтожена книга «Без названия» (деструктор). Книг сейчас: 3
  [-] Уничтожена книга «Мастер и Маргарита» (деструктор). Книг сейчас: 2
После блока Book::getCount() = 2
```

*Отказ в выдаче уже выданной книги и время жизни объектов: книги, созданные внутри блока, уничтожаются при выходе из него в обратном порядке, и статический счётчик уменьшается. Остальной вывод сокращён до `...`.*

## Требования

- Компилятор g++ с поддержкой C++14. Проверено на g++ 16.2.0 (MinGW-w64, Windows 10).
- Doxygen — для сборки документации, необязательно. Проверено на версии 1.18.0.
- PlantUML — для диаграммы в документации Doxygen, необязательно. Проверено на версии 1.2026.8 (Java 8).

## Сборка и запуск

**Windows** (cmd или PowerShell):

```console
$ .\build.bat
Сборка успешна: build\lab2.exe
```

```powershell
.\build\lab2.exe
```

Что произошло:

- `build.bat` собрал программу из файлов папки `src` с флагами `-std=c++14 -Wall -Wextra -pedantic -static`; предупреждений компилятора нет.
- Флаг `-static` встраивает библиотеки MinGW в `lab2.exe`, поэтому программа запускается и на компьютере без компилятора. В конце программа ждёт нажатия Enter, чтобы окно не закрылось сразу.

**Linux и macOS** — на этих системах сборка не проверялась:

```bash
g++ -std=c++14 -Wall -Wextra -pedantic -Iinclude src/*.cpp -o lab2
./lab2
```

## Как это работает

Класс `Book` описывает один экземпляр книги в библиотеке: название, автор, год издания, положение (на полке, у читателя или списана) и число выдач. Все поля закрыты (`private`), доступ к ним — через константные методы чтения. Автор — объект отдельного класса `Author`: так выполнено требование, чтобы одно из полей имело пользовательский тип.

Все конструкторы заполняют поля в списке инициализации. Параметризованный конструктор проверяет инварианты — непустое название и год издания от 1450 до текущего года, позже года рождения автора — и при нарушении бросает исключение `std::invalid_argument`, поэтому некорректная книга не может быть создана.

Состояние книги меняют только действия библиотеки: `issueTo` (выдать), `returnBook` (вернуть), `writeOff` (списать). Сеттеров нет. Каждый метод сначала проверяет все условия и при недопустимой операции возвращает `false`, сообщает причину и не меняет ни одно поле. Статическое поле `count_` хранит число существующих книг: его увеличивают все конструкторы, включая конструктор копирования, а уменьшает деструктор, который заодно сообщает о конце жизни объекта.

Подробнее — на страницах [«Часть 1. Проектирование класса Book»](pages/design.md) и [«Часть 2. Изменение состояния, деструктор и счётчик объектов»](pages/state.md).

## Документация

Комментарии в коде оформлены для Doxygen. Соберите документацию:

```bash
doxygen Doxyfile
```

Откройте `docs/html/index.html`. Сборка проходит без предупреждений. Диаграмму классов Doxygen рисует через PlantUML; путь к `plantuml.jar` задан в `Doxyfile` (`PLANTUML_JAR_PATH`) — на другом компьютере его нужно поправить. Что изменилось в каждой версии — в [CHANGELOG.md](CHANGELOG.md).
