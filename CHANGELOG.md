# История версий

Здесь записано, что было сделано в каждой версии лабораторной работы.
Каждой версии в git соответствует метка (тег) с тем же именем.
Новые версии добавляются сверху.

## v0.2 — 2026-10-03

Выполнена часть 2 из 3: методы изменения состояния, явный деструктор и статический счётчик
объектов.

### Сделано

- Методы изменения `issueTo(reader)`, `returnBook()`, `writeOff()` (`Book.h` / `Book.cpp`): проверяют
  инварианты 3–5 и при недопустимой операции возвращают `false`, сообщают причину и не меняют книгу.
- Статическое поле `count_` и статический метод `getCount()`: счётчик увеличивают все три
  конструктора (в параметризованном — только после успешных проверок), уменьшает деструктор.
- Явный деструктор `~Book()`: уменьшает счётчик и сообщает о конце жизни объекта; конструкторы
  сообщают о создании.
- Оператор присваивания объявлен явно как `= default`: он не создаёт новой книги и счётчик не меняет.
- `main()`: успешные и отклонённые операции, счётчик до, внутри и после блока, момент вызова
  деструкторов (демонстрация — в функции `runDemo()`).
- Страница документации `pages/state.md`; на диаграмму классов добавлен оператор присваивания;
  README описывает части 1 и 2.

### Проверено

- Сборка `g++ -std=c++14 -Wall -Wextra -pedantic -static` (g++ 16.2.0) — без ошибок и предупреждений.
- Тестовая программа части 2 — 35 проверок из 35: счётчик при каждом конструкторе, при исключении в
  конструкторе, при присваивании, при выходе из блока, при `new` и `delete`; успешные операции;
  каждый отказ оставляет книгу без изменений; копия независима от оригинала. Проверки части 1 —
  23 из 23.
- Doxygen 1.18.0 собирает документацию без предупреждений.

### Следующая версия (v1.0)

- Этап №3: функция `main()` — тест класса из шести этапов (создание объектов, начальное состояние,
  корректные и некорректные операции, повторный вывод, независимость объектов).

## v0.1 — 2026-10-03

Выполнена часть 1 из 3: проектирование класса Book (вариант 5 — книга из библиотеки),
конструкторы и методы чтения.

### Сделано

- Страница `pages/design.md`: этап №1 (ответы на четыре вопроса о сущности), этап №2 (таблица
  проектирования), пять инвариантов, сверка с обязательными требованиями.
- Диаграмма классов в PlantUML: `uml/Book.puml` и картинка `uml/Book.png`.
- Класс `Author` (`Author.h` / `Author.cpp`) — автор книги, пользовательский тип для поля
  `Book::author_`; проверяет имя и год рождения.
- Класс `Book` (`Book.h` / `Book.cpp`): семь полей в секции `private`; конструктор по умолчанию,
  параметризованный конструктор с проверкой инвариантов (исключение `std::invalid_argument`) и
  конструктор копирования — все со списками инициализации; константные методы чтения; `print()`.
- Функция `currentYear()` — текущий год для проверки годов.
- `main()`: книги, созданные тремя способами, и попытка создать некорректную книгу.

### Проверено

- Сборка `g++ -std=c++14 -Wall -Wextra -pedantic -static` (g++ 16.2.0) — без ошибок и предупреждений.
- Тестовая программа: конструкторы и инварианты Author и Book, граничные годы (1449 и 1450,
  текущий и следующий год, год рождения автора), значения по умолчанию, копирование —
  23 проверки из 23.
- Doxygen 1.18.0 собирает документацию без предупреждений; диаграмма — PlantUML 1.2026.8.

### Следующая версия (v0.2)

- Методы изменения `issueTo`, `returnBook`, `writeOff` с проверкой инвариантов, явный деструктор,
  статический счётчик существующих объектов.
