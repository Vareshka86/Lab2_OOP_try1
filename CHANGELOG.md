# История версий

Здесь записано, что было сделано в каждой версии лабораторной работы.
Каждой версии в git соответствует метка (тег) с тем же именем.
Новые версии добавляются сверху.

## v0.1 — 2026-10-03

Выполнена часть 1 из 3: проектирование класса Book (вариант 5 — книга из библиотеки),
конструкторы и методы чтения.

### Сделано

- Страница `pages/design.md`: этап №1 (ответы на четыре вопроса о сущности), этап №2 (таблица
  проектирования), пять инвариантов, сверка с обязательными требованиями.
- Диаграмма классов в PlantUML: `uml/Book.puml` и картинка `uml/Book.png`.
- Класс `Author` (`Author.h` / `Author.cpp`) — автор книги, пользовательский тип для поля
  `Book::author_`; проверяет имя и год рождения.
- Класс `Book` (`Book.h` / `Book.cpp`): семь полей в секции `private`; конструктор по умолчанию,
  параметризованный конструктор с проверкой инвариантов (исключение `std::invalid_argument`) и
  конструктор копирования — все со списками инициализации; константные методы чтения; `print()`.
- Функция `currentYear()` — текущий год для проверки годов.
- `main()`: книги, созданные тремя способами, и попытка создать некорректную книгу.

### Проверено

- Сборка `g++ -std=c++14 -Wall -Wextra -pedantic -static` (g++ 16.2.0) — без ошибок и предупреждений.
- Тестовая программа: конструкторы и инварианты Author и Book, граничные годы (1449 и 1450,
  текущий и следующий год, год рождения автора), значения по умолчанию, копирование —
  23 проверки из 23.
- Doxygen 1.18.0 собирает документацию без предупреждений; диаграмма — PlantUML 1.2026.8.

### Следующая версия (v0.2)

- Методы изменения `issueTo`, `returnBook`, `writeOff` с проверкой инвариантов, явный деструктор,
  статический счётчик существующих объектов.
